Projeto: O que ela gosta, o que ele gosta
Autor: Jorge Luiz
Trilha: 1

A ideia deste projeto é testar meu conhecimento utilizando o Unity

O projeto possui 3 plantas e 1 nave, representando o que minha esposa mais gosta e o que eu gosto (dá pra ver até pelo ambiente em que coloquei no sky)

Coloquei paredes, texturas, objetos que podem ser pegos, o vidro que não tem colisão, os totens que possuem colisão, tudo isso seguindo os passos do professor Felipe

Já verifiquei, e não tem mais erros pra dar FIX

Para interação, o usuario pode pegar os objetos que coloquei no senário, mostrando que corresponde a parte avançada do exercício
